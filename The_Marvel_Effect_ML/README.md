# The Marvel Effect — Comic UI ML Prototype

## Visual version
```bash
pip install -r requirements.txt
python -m streamlit run app/app.py
```

## Terminal version
The main visual build is `app/app.py`. The model uses the same KNN distance ranking for the primary match and Top 3.

The UI uses only CSS/HTML styling — no image assets are required.

Theme:
- Ink black
- Comic red
- Muted tactical green
- Aged paper cream
- Handwritten/comic typography
- Halftone/print-inspired texture
- Torn-paper style panels

The character feature values are engineered prototype reference values.
The displayed match score is a distance-based similarity score, not a probability or psychological diagnosis.
